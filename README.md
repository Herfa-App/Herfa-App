Project Name: Herfa

Introduction
This mobile application is a specialized platform for home services and craftsmanship in Egypt. It is developed as a graduation project for the Digital Egypt Builders Initiative (DEBI). The app bridges the gap between verified service providers and household clients, ensuring easy access to maintenance professionals in various regions.

Objectives

-Enable clients to browse and hire skilled professionals including plumbers, electricians, and carpenters.

-Provide a dedicated space for craftsmen to showcase their expertise and reach a wider customer base in their governorates.

-Offer a cross-platform experience using Flutter to ensure high performance and accessibility.

Core Features

-Geographical search to find the nearest craftsman based on the user's location.

-Service categorization by craft type for quick navigation.

-Professional profiles for service providers including contact information.

Technical Overview

-Framework: Flutter.

-Programming Language: Dart.
